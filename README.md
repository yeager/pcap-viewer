# PacketLens

PCAP network capture analyzer with protocol dissection.

Built with GTK4/Adwaita. Part of the [Danne L10n Suite](https://github.com/yeager/debian-repo).

## Installation

### Debian/Ubuntu
```bash
sudo apt install pcap-viewer
```

### Fedora/RPM
```bash
sudo dnf install pcap-viewer
```
