# PacketLens Screenshots

This directory contains screenshots of PacketLens showing its various analysis features.

## Screenshot Files

- `packetlens-packets.png` - Main packet list view with three-pane layout
- `packetlens-conversations.png` - Conversation analysis showing network flows  
- `packetlens-protocol-stats.png` - Protocol statistics with pie charts and breakdowns
- `packetlens-dns.png` - DNS analysis tab showing query/response tracking
- `packetlens-http.png` - HTTP analysis with request/response extraction
- `packetlens-tls.png` - TLS analysis showing certificates and cipher suites
- `packetlens-files.png` - File extraction interface showing recovered files
- `packetlens-timeline.png` - Timeline view with chronological network events

## Screenshot Specifications

- **Language**: English (LANG=en_US.UTF-8)  
- **Display**: X11 with Cairo renderer for crisp UI elements
- **Format**: PNG with transparency support
- **Size**: Approximately 1280x720 (desktop resolution)
- **Test Data**: Generated using comprehensive scapy-based PCAP with:
  - DNS queries/responses (multiple domains)
  - HTTP traffic (GET, POST, PUT, DELETE methods)  
  - TLS handshakes
  - ICMP ping/pong
  - UDP syslog traffic
  - TCP connection errors

## Generation

Screenshots are automatically generated by the testing script on burken:
```bash
/tmp/packetlens-test-script.sh
```

Each screenshot shows PacketLens loaded with realistic test data to demonstrate the full capabilities of each analysis view.
